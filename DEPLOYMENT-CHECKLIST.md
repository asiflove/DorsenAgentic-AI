# Deployment checklist

- [ ] Create GitHub account (with parent/guardian assistance if needed).
- [ ] Create repository `dorsenagentic-ai`.
- [ ] Upload all project files to the repository root.
- [ ] Connect the repository in Cloudflare Pages.
- [ ] Build command: `npm run build`.
- [ ] Build output directory: `out`.
- [ ] Confirm successful deployment in Cloudflare.
- [ ] Check the assigned `pages.dev` address and project-name availability.
- [ ] Test navigation and mobile layout on iPhone.

A successful deployment publishes the static preview only. AI, accounts and database integrations are not active in this phase.
